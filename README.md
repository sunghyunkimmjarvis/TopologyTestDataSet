# Topology-Aware Boundary-Condition Inference Dataset for STEP B-Rep Models

This repository provides the parametric CAD dataset used in the study:

**“Topology-Aware Boundary-Condition Inference for Finite Element Preprocessing from STEP B-Rep Models”**

The dataset was created to investigate automatic finite element analysis (FEA) boundary-condition inference from STEP-based boundary-representation (B-Rep) CAD models using node-based and graph-based machine-learning methods.

## Overview

Each CAD model is represented as a face-level graph derived directly from its STEP B-Rep structure.

* **Graph nodes:** CAD faces
* **Graph edges:** adjacency relationships between faces sharing a common boundary edge
* **Node labels:**

  * `0` — General / unconstrained face
  * `1` — Fixed-boundary face
  * `2` — Load-applied face
* **Node features:** face-level geometric descriptors
* **Edge features:** geometric information associated with shared edges

The dataset is intended for research on CAD-to-FEA automation, graph neural networks (GNNs), B-Rep representation learning, and boundary-condition inference.

## Dataset Composition

The repository contains **4,454 parametric CAD models** from five mechanical design families.

|CAD Family|Number of Models|Topological Variation|
|-|-:|-|
|Cantilever Beam|1,701|Single topology|
|Bookshelves|1,155|Single topology|
|L-Shaped Bracket|525|Single topology|
|Flange|864|Three topologies|
|ISO 4017 Bolt|209|Single topology|
|**Total**|**4,454**|—|

The flange family contains controlled topological variation generated by changing the bolt-hole count. The other four families retain the same graph topology while their geometric dimensions vary.

## Graph Representation

Each STEP model is converted into a graph:

\[
G = (V, E, X, A)
]

where:

* (V) is the set of B-Rep faces,
* (E) is the set of shared-edge relations,
* (X) is the node-feature matrix,
* (A) is the binary face-adjacency matrix.

Two face nodes are connected when the corresponding CAD faces share a common B-Rep edge.

## Node Features

Each face is represented using geometric descriptors extracted from the STEP model.

The feature set includes:

1. Number of boundary curves
2. Number of line edges
3. Number of arc edges
4. Number of spline edges
5. Maximum edge length
6. Minimum edge length
7. Mean edge length
8. Mean X coordinate
9. Mean Y coordinate
10. Mean Z coordinate
11. Surface type

Surface types are integer encoded as:

|Code|Surface Type|
|-:|-|
|0|Plane|
|1|Cylindrical|
|2|Spherical|
|3|Conical|
|4|Toroidal|
|5|NURBS|
|6|Other|

The boundary-condition label is stored separately from the input features.

## Edge Features

For graph models that use attributed edges, each shared B-Rep edge is described using geometric relationship information between adjacent faces.

The edge representation includes:

* Convexity
* Normalized dihedral angle
* Shared-edge length
* Edge type

These features are used to study whether geometric relationships between adjacent faces provide information beyond binary graph connectivity.

## Boundary-Condition Labels

The dataset contains three face-level classes:

|Label|Meaning|
|-:|-|
|0|General / unconstrained surface|
|1|Fixed surface|
|2|Load-applied surface|

Because no public dataset currently provides the same face-level FEA boundary-condition annotations for these parametric CAD families, the labels were assigned according to predefined structural-analysis scenarios and applied consistently within each design family.

## Research Use

The dataset was designed to support experiments involving:

* Face-level boundary-condition classification
* CAD-to-FEA preprocessing automation
* Comparison of MLP and GNN architectures
* Analysis of graph-topology contribution
* Coordinate-ablation studies
* Edge-feature ablation studies
* Representational upper-bound analysis
* Leave-one-family-out generalization
* STEP B-Rep graph learning

The associated study compares:

* Multilayer Perceptron (MLP)
* Graph Convolutional Network (GCN)
* GraphSAGE
* Graph Isomorphism Network (GIN)
* Graph Isomorphism Network with Edge Features (GINE)

## Important Scope and Limitations

This dataset consists of **synthetic parametric CAD models** and uses **one predefined analysis scenario per design family**.

The dataset is therefore primarily intended to evaluate:

* within-family parametric generalization,
* the contribution of B-Rep topology,
* the contribution of geometric edge information, and
* representational limits of geometry- and topology-based boundary-condition inference.

Performance obtained from this dataset should not be interpreted as general boundary-condition reasoning across arbitrary industrial CAD models or arbitrary FEA scenarios.
